# School-Management-System-SQL-Project

## 📌 Project Overview
This project is a SQL-based School Management System created using MySQL. It demonstrates database design, SQL query writing, and data analysis concepts.

## Project Features
- Manage student, teacher, and course records.
- Perform data filtering and sorting.
- Analyze data using SQL queries.
- Generate reports using SQL concepts.

## 🛠️ Tools Used
- MySQL
- SQL

## 📂 Database Tables
- Students
- Teachers
- Courses

## 📚 SQL Concepts Used
- SELECT
- WHERE
- ORDER BY
- GROUP BY
- Aggregate Functions
- JOINS
- Subqueries
- LIMIT

 ## How to Run

1. Open MySQL Workbench.
2. Create a new database.
3. Import the SQL file.
4. Run the SQL script.
5. Execute the queries.

 ## Sample Queries

- Display all students.
- Find students from Delhi.
- Show top 5 students by marks.
- Display average marks.
- Retrieve data using JOINs.
